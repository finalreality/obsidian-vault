<h2 id="前言" tid="tid-8sEp6i">前言<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h2>
<p>用了几年vim，但是有些命令少用后便会忘记，时常需要百度，干脆在这里累积，方便直接查找。</p>

<h2 id="vim简要知识" tid="tid-BsHh3s">vim简要知识<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h2>
<h3 id="vim键盘简图" tid="tid-nGB3ZK">vim键盘简图<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h3>

<h3 id="vim模式" tid="tid-R7ABct">vim模式<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h3>
<ol>
<li>普通模式：Vim 启动后的默认模式，用来移动光标、删除文本、覆盖输入文本、恢复操作、粘贴文本等等。</li>
<li>插入模式：输入 <code>i</code> 或 <code>a</code> 或 <code>o</code> 进入插入模式，在这个模式下敲击键盘会往文字缓冲区增加文字，相当于普通编辑器的编辑模式。</li>
<li>可视模式：选择文本，可以行选、块选和依次选择，选择后可以进行复制、删除、排序等操作。</li>
<li>命令模式：执行内部和外部命令，通过<code>:</code>、<code>/</code>、<code>?</code>、<code>:!</code>可以进入命令模式，分别对应的是：执行内部命令、向上或向下搜索、执行外部命令。</li>
</ol>
<h2 id="vim日常操作" tid="tid-cws6SR">vim日常操作<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h2>
<p>以下描述，默认情况都是在普通模式下的键入。</p>
<p>只描述本人日常使用的，一切少用和不常见的可以参考上图或百度。</p>
<h3 id="光标移动" tid="tid-EDWrdN">光标移动<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h3>
<h4 id="上下左右" tid="tid-kZehF5">上下左右：<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h4>
<p>普通模式和可视模式下，使用<code>h</code>（←）、<code>j</code>（↓）、<code>k</code>（↑）、<code>l</code>（→）实现。</p>
<p><a data-fancybox="gallery" href="https://img2023.cnblogs.com/blog/2085252/202212/2085252-20221204130235132-379463758.png"><img src="https://img2023.cnblogs.com/blog/2085252/202212/2085252-20221204130235132-379463758.png"></a></p>
<p>如果需要在插入模式下实现光标移动，可以在vimrc文件配置上添加以下配置热键映射（入门的同学忽略这个）</p>
<ul>
<li><em>个人习惯键盘默认的上下左右键。</em></li>
</ul>
<p>单词方式移动光标（<em>不区分大小写</em>）：</p>
<ul>
<li><code>b</code>/<code>B</code>：前一个单词词首。</li>
<li><code>e</code>/<code>E</code>：下一个单词词尾。</li>
<li><code>w</code>/<code>W</code>：下一个单词词首。</li>
</ul>
<h4 id="行指定字符" tid="tid-K836Zt">行指定字符：<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h4>
<ul>
<li><code>f</code>x：搜索光标后字符x并跳转。</li>
<li><code>F</code>x：搜索光标前字符x并跳转。</li>
</ul>
<p><a data-fancybox="gallery" href="https://img2023.cnblogs.com/blog/2085252/202212/2085252-20221204130452656-1046752738.gif"><img src="https://img2023.cnblogs.com/blog/2085252/202212/2085252-20221204130452656-1046752738.gif"></a></p>
<h4 id="行首行尾" tid="tid-HtsX2Z">行首行尾：<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h4>
<ul>
<li><code>home</code>和<code>end</code>键：行首尾。虽然不属于vim范畴，但是作者也经常使用。特别是搭配<code>shift</code>键用来选中文本。</li>
<li><code>^</code>和<code>$</code>，也是行首尾。</li>
<li><code>|</code>（是<code>shift</code>+<code>\</code>得出的，不是英文字母<code>I</code>）：行首。<br>
<a data-fancybox="gallery" href="https://img2023.cnblogs.com/blog/2085252/202212/2085252-20221204130515973-468877341.gif"><img src="https://img2023.cnblogs.com/blog/2085252/202212/2085252-20221204130515973-468877341.gif"></a></li>
</ul>
<h4 id="句和段" tid="tid-Mjzk27">句和段：<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h4>
<ul>
<li><code>(</code>和<code>)</code>：上一句和下一句。</li>
<li><code>{</code>和<code>}</code>：上一段和下一段。</li>
</ul>
<h4 id="文件某个位置" tid="tid-xBii7H">文件某个位置：<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h4>
<ul>
<li><code>gg</code>：文件头。</li>
<li><code>G</code>：文件末。</li>
<li>n<code>gg</code>：跳转到第n行，n为数字。</li>
</ul>
<p><a data-fancybox="gallery" href="https://img2023.cnblogs.com/blog/2085252/202212/2085252-20221204130556229-1105899786.gif"><img src="https://img2023.cnblogs.com/blog/2085252/202212/2085252-20221204130556229-1105899786.gif"></a></p>
<h4 id="跳到函数首尾" tid="tid-ChWkp8">跳到函数首尾：<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h4>
<p><code>[</code>和<code>]</code>都是以每个函数的首尾括号为基准。</p>
<p>相同方向跳到函数左括号（开头）。</p>
<p>相反方向跳到函数右括号（尾部）。</p>
<p>第一个方向决定前后，第二个方向决定首尾。</p>
<p>前面还可以添加数字n，表示n个。</p>
<p>n不填时默认为1。</p>
<p><code>n[[</code>：前n个  前：<code>(</code>。</p>
<p><code>n[]</code>：前n个  后：<code>)</code>。</p>
<p><code>n]]</code>：后n个  前：<code>(</code>。</p>
<p><code>n][</code>：后n个  后：<code>)</code>。</p>
<p><code>ctrl+T</code>：回到上一个光标位置。</p>
<h3 id="屏幕移动" tid="tid-EPDrbS">屏幕移动<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h3>
<p>主要是浏览代码时使用。</p>
<h4 id="翻页" tid="tid-SfHtf5">翻页：<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h4>
<ul>
<li><code>ctrl</code>+<code>b</code>：上一页。(Backward)</li>
<li><code>ctrl</code>+<code>f</code>：下一页。(Forward)</li>
<li><code>ctrl</code>+<code>u</code>：上半一页。(up)</li>
<li><code>ctrl</code>+<code>d</code>：下半一页。(down)</li>
</ul>
<h4 id="当前屏光标位置" tid="tid-t5jSK7">当前屏光标位置：<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h4>
<ul>
<li><code>H</code>：当前屏顶。（High）</li>
<li><code>M</code>：当前屏中。（Middle）</li>
<li><code>L</code>：当前屏底。（Low）</li>
</ul>
<h4 id="光标滚屏" tid="tid-AzEm8x">光标滚屏：<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h4>
<ul>
<li><code>zt</code>：光标代码滚到屏顶。（top）</li>
<li><code>zz</code>：光标代码滚到屏中。</li>
<li><code>zb</code>：光标代码滚到屏底。</li>
<li><code>ctrl</code>+<code>e</code>：前滚一行。</li>
<li><code>ctrl</code>+<code>y</code>：后滚一行。</li>
</ul>
<h3 id="文本修改" tid="tid-A3XWYZ">文本修改<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h3>
<h4 id="进入插入模式" tid="tid-DkesKr">进入插入模式：<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h4>
<ul>
<li><code>i</code>：在光标所在位置插入。</li>
<li><code>I</code>：在行首插入。</li>
<li><code>a</code>：在在光标后插入。</li>
<li><code>A</code>：在行尾插入。</li>
<li><code>o</code>：在光标所在位置的下一行插入。</li>
<li><code>O</code>：在光标所在位置的上一行插入。</li>
</ul>
<h4 id="删除" tid="tid-EpNWXF">删除：<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h4>
<p><code>x</code>：删除字符。</p>
<ul>
<li><code>x</code>：删除当前字符。</li>
<li>n<code>x</code>：删除包括当前字符后的n个字符。</li>
<li><code>X</code>：删除光标前一个字符。</li>
<li>n<code>X</code>：删除当前光标前的n个字符。</li>
</ul>
<p><code>d</code>：需要配合使用。</p>
<ul>
<li>
<p><code>dd</code>：删除整行。</p>
</li>
<li>
<p>n<code>dd</code>：删除n行。</p>
</li>
<li>
<p>因为<code>d</code>是删除操作，需要搭配其它键使用，其删除就是删除到后面键入命令后光标的位置如：</p>
<ul>
<li><code>df</code>x：从光标起删除到本行后面第一个字符x的位置。</li>
<li><code>diw</code>：删除光标所在单词。</li>
<li>还有<code>dw</code>、<code>db</code>、<code>d end键</code>等等都可以自由发挥。</li>
</ul>
</li>
</ul>
<p><code>di</code>x和<code>da</code>x的使用，是删除x内部和删除包括x的内部：</p>
<ul>
<li><code>di}</code>：就是删除光标所在的<code>{}</code>内部所有内容。</li>
<li><code>da}</code>：相对<code>di}</code>，<code>da}</code>把<code>{}</code>也删除。</li>
<li>其x可以搭配：<code>w</code>、<code>s</code>、<code>p</code>、<code>"</code>、<code>}</code>、<code>]</code>等等辅助字符，实际用到时再了解。</li>
</ul>
<p><code>diw</code>删除一个单词示例：</p>

<h2 id="多窗口" tid="tid-wmj5Fj">多窗口<button class="cnblogs-toc-button" title="显示目录导航" aria-expanded="false"></button></h2>
<p>多个窗口操作同一个文件。</p>
<p><code>:sp</code>：水平分屏。（split）</p>
<p><code>:vs</code>：垂直分屏。（vsplit）</p>
<p>注意，部分功能渲染在vscode可能失效，练习的同学转linux下的vim。</p>
<p>操作下面处理前先键入<code>ctrl</code>+<code>w</code>：</p>
<p>主要：</p>
<ul>
<li>加方向键（h、j、k、l、<left>等等）可以在窗口之间跳转</left></li>
<li><code>w</code>：跳转到下一个（往右和往下）窗口，如果已经是右下角的窗口，则跳转到左上角的窗口</li>
<li><code>W</code>：跳转到上一个（往左和往上）窗口，如果已经是左上角的窗口，则跳转到右下角的窗口</li>
<li><code>n</code>或<code>:new</code>：打开一个新窗口</li>
<li><code>c</code>或<code>:close</code>：关闭当前窗口；当前窗口如果已经是最后一个则无效</li>
<li><code>q</code>或<code>:quit</code>：退出当前窗口，当最后一个窗口退出时则退出 Vim</li>
<li><code>o</code>或<code>:only</code>：只保留当前窗口，关闭其他所有窗口</li>
<li><code>s</code>和<code>:split</code>：作用相同，把当前窗口横向一分为二</li>
<li><code>v</code>和<code>:vsplit</code>：作用相同，把当前窗口纵向一分为二</li>
<li><code>=</code>：使得所有窗口大小相同（当调整过终端或图形界面 Vim 的窗口大小后特别有用）</li>
</ul>
<p>了解：</p>
<ul>
<li><code>_</code>：设置窗口高度，命令前的数字表示高度行数，默认为纵向占满（想专心编辑某个文件时很有用）</li>
<li><code>|</code>：设置窗口宽度，命令前的数字表示宽度列数，默认为横向占满</li>
<li><code>+</code>：增加窗口的高度，命令前的数字表示需要增加的行数，默认为 1</li>
<li><code>-</code>：减少窗口的高度，命令前的数字表示需要减少的行数，默认为 1</li>
<li><code>&gt;</code>：增加窗口的宽度，命令前的数字表示需要增加的列数，默认为 1</li>
<li>&lt;<code>lt</code>&gt;（提醒，我们用<lt>表示“&lt;”键）减少窗口的宽度，命令前的数字表示需要增加的列数，默认为 1。</lt></li>
</ul>
