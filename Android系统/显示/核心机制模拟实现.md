# 核心机制模拟实现 (C++ Pseudo-Code)

为了理解 `SurfaceFlinger` 与 `BufferQueue` 的协作，下面提供一个简化的 C++ 模拟实现。

```cpp
#include <iostream>
#include <queue>
#include <vector>
#include <string>

// 模拟图形缓冲区
struct GraphicBuffer {
    int id;
    std::string data;
};

// 1. BufferQueue: 生产者与消费者的中转站
class BufferQueue {
private:
    std::queue<GraphicBuffer*> queue;
public:
    void enqueueBuffer(GraphicBuffer* buffer) {
        std::cout << "[BufferQueue] Received Buffer ID: " << buffer->id << std::endl;
        queue.push(buffer);
    }

    GraphicBuffer* dequeueBuffer() {
        if (queue.empty()) return nullptr;
        GraphicBuffer* buf = queue.front();
        queue.pop();
        return buf;
    }

    bool hasBuffer() { return !queue.empty(); }
};

// 2. Layer: 代表一个窗口图层
class Layer {
public:
    std::string name;
    BufferQueue* queue;
    Layer(std::string n, BufferQueue* q) : name(n), queue(q) {}
};

// 3. SurfaceFlinger: 核心合成器
class SurfaceFlinger {
private:
    std::vector<Layer*> layers;
public:
    void addLayer(Layer* layer) {
        layers.push_back(layer);
    }

    // 模拟 VSYNC 触发的合成过程
    void onVsync() {
        std::cout << "\n--- VSYNC Signal Received: Starting Composition ---" << std::endl;
        for (auto& layer : layers) {
            GraphicBuffer* buf = layer->queue->dequeueBuffer();
            if (buf) {
                std::cout << "[SurfaceFlinger] Compositing Layer: " << layer->name
                          << " with Buffer Content: " << buf->data << std::endl;
            } else {
                std::cout << "[SurfaceFlinger] Layer " << layer->name << " has no new buffer." << std::endl;
            }
        }
        std::cout << "--- Composition Finished ---\n" << std::endl;
    }
};

// 4. 模拟运行
int main() {
    // 初始化系统组件
    BufferQueue appQueue;
    SurfaceFlinger sf;

    // 创建应用层 (Producer)
    Layer* appLayer = new Layer("App_Window", &appQueue);
    sf.addLayer(appLayer);

    // 模拟 App 生产数据
    GraphicBuffer* frame1 = new GraphicBuffer{1, "Pixel_Data_Frame_1"};
    GraphicBuffer* frame2 = new GraphicBuffer{2, "Pixel_Data_Frame_2"};

    std::cout << "[App] Producing Frame 1..." << std::endl;
    appQueue.enqueueBuffer(frame1);

    // 模拟 VSYNC 第一次触发
    sf.onVsync();

    std::cout << "[App] Producing Frame 2..." << std::endl;
    appQueue.enqueueBuffer(frame2);

    // 模拟 Vsync 第二次触发
    sf.onVsync();

    // 清理内存 (实际开发中需使用智能指针)
    delete frame1;
    delete frame2;
    delete appLayer;

    return 0;
}
```

### 代码逻辑说明：
1.  **`GraphicBuffer`**: 模拟了内存中的像素数据。
2.  **`BufferQueue`**: 实现了一个简单的 `std::queue`，模拟了 Android 的 `BufferQueue` 异步传递特性。
3.  **`SurfaceFlinger::onVsync`**: 模拟了 Android 驱动层发送 VSYNC 信号后，系统遍历所有 Layer 并从对应的 Queue
中提取 Buffer 进行合成的操作。
4.  **解耦**: 注意到 `App` 只负责 `enqueue`，而 `SurfaceFlinger` 只负责 `dequeue`。两者通过 `BufferQueue` 实现解
耦，这就是 Android 能够实现高帧率流畅度的关键。
