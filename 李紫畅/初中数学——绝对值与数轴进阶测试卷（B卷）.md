#### **三、解答题**

**11. 计算与化简：**  
(1) 解：原式 = | -2 | - | 2 | = 2 - 2 = **0**  
(2) 解：∵ 1 < x < 5, ∴ x - 1 > 0, 5 - x > 0.  
∴ 原式 = (x - 1) + (5 - x) = x - 1 + 5 - x = **4**  
(3) 解：由数轴位置可知：a<0 ∴ |a| = -a; a+b<0 ∴ |a+b| = -(a+b); c-a>0 ∴ |c-a| = c-a; b+c符号不确定，但b<0, c>0且|b|>|c|，∴ b+c<0，|b+c| = -(b+c)  
∴ 原式 = (-a) - (-(a+b)) + (c - a) + (-(b+c))  
= -a + a + b + c - a - b - c  
= **-a**

**12. 应用与推理：**  
(1) 解：∵ |a| = 5, ∴ a = 5 或 a = -5.  
b 是最大的负整数，∴ b = -1.  
c 是绝对值最小的数，∴ c = 0.  
当 a=5 时，a - b - c = 5 - (-1) - 0 = 6.  
当 a=-5 时，a - b - c = -5 - (-1) - 0 = -4.  
∴ a - b - c 的值为 **6 或 -4**.  
(2) 解：∵ |a-2| 与 |b+5| 互为相反数，且两者均为非负数。  
∴ |a-2| = 0 且 |b+5| = 0.  
∴ a = 2, b = -5.  
∴ aᵇ = 2⁻⁵ = **1/32**.

**13. 探索与发现：**  
(1) **7**  
(2) **5**  
(3) **分析：** |x-5| + |x+2| = 9 的几何意义是：点x到5的距离与到-2的距离之和为9。  
数轴上5和-2之间的距离是7。  
∴ 点x不能在-2和5之间（此时和恒为7）。  
当点x在5的右侧时，有 (x - 5) + (x - (-2)) = 9 => 2x -3 =9 => x=6.  
当点x在-2的左侧时，有 (5 - x) + (-2 - x) = 9 => -2x +3 =9 => x=-3.  
**答：所有符合条件的整数 x 为 -3 和 6。**  
(4) **有最小值。**  
**最小值是 7。**  
**此时 x 的取值范围是 -2 ≤ x ≤ 5。**

**14. 综合与实践：**  
(1) **分析：** 判断误差的绝对值是否 ≤ 0.3。  
|+0.1|=0.1≤0.3，合格。  
|-0.2|=0.2≤0.3，合格。  
|+0.3|=0.3≤0.3，合格。  
|-0.05|=0.05≤0.3，合格。  
|+0.35|=0.35>0.3，不合格。  
|-0.25|=0.25≤0.3，合格。  
|0|=0≤0.3，合格。  
|-0.4|=0.4>0.3，不合格。  
**答：误差为 +0.1, -0.2, +0.3, -0.05, -0.25, 0mm 的零件是合格品。**

(2) **分析：** 误差的绝对值越小，质量越高。  
|0| = 0 （最小）  
|-0.05| = 0.05  
|+0.1| = 0.1  
|-0.2| = 0.2  
|-0.25| = 0.25  
|+0.3| = 0.3 （最大）  
**答：质量最高的零件是误差为 0mm 的零件，因为它的误差绝对值为0，最接近标准长度。质量最低的合格零件是误差为 +0.3mm（或 -0.3mm，本题中为+0.3）的零件，因为它的误差绝对值在合格品中是最大的。**

(3) **解：** 实际长度 = 标准长度 + 误差 = (20 + x) mm.
