#### **三、解答题**

**11. 计算：**  
(1) 解：原式 = 8 - 5 = **3**  
(2) 解：原式 = 12 ÷ 4 = **3**  
(3) 解：∵ π ≈ 3.14 > 3, ∴ π - 3 > 0, |π - 3| = π - 3  
∵ π ≈ 3.14 < 4, ∴ 4 - π > 0, |4 - π| = 4 - π  
∴ 原式 = (π - 3) + (4 - π) = π - 3 + 4 - π = **1**

**12. 数轴表示与比较大小：**

- **化简各数：**  
    -(-3) = 3  
    -|-2.5| = -2.5  
    | -4 | = 4
    
- **在数轴上表示：**  
    （请想象一条数轴，从左到右依次标出：-2.5, -1, 0, 3, 4）
    
- **大小比较：**  
    -|-2.5| < -1 < 0 < -(-3) < | -4 | 或 **-2.5 < -1 < 0 < 3 < 4**
    

**13. 足球质量检查：**

- **分析：** 质量是否符合标准，关键看其**偏差的绝对值**是否 ≤ 15。
    
- **判断：**  
    | -12 | = 12 ≤ 15，符合  
    | +8 | = 8 ≤ 15，符合  
    | -5 | = 5 ≤ 15，符合  
    | +15 | = 15 ≤ 15，符合（“不得超过”包含等于）  
    | -20 | = 20 > 15，不符合  
    | +3 | = 3 ≤ 15，符合
    
- **答：** 偏差为 -12g, +8g, -5g, +15g, +3g 的足球质量符合标准，偏差为 -20g 的足球不符合标准。
    

**14. 求 a, b 的值：**

- ∵ |a| = 5, ∴ a = 5 或 a = -5  
    ∵ |b| = 2, ∴ b = 2 或 b = -2
    
- **条件：a < b**
    
    - 若 a = 5，则 5 不可能小于 2 或 -2，舍去。
        
    - 若 a = -5，则 -5 < 2 且 -5 < -2。
        
- **∴ a = -5**  
    **b = 2 或 b = -2**
    

**15. 数形结合探究：**  
(1) |3 - 1| 表示数轴上表示 **3** 和表示 **1** 的两点之间的距离。这个距离是 **2**。  
(2) |x - 1| 的几何意义是：数轴上表示数 **x** 的点与表示数 **1** 的点之间的距离。  
(3) 当 x = **5** 时，|x - 5| 的值最小，最小值是 **0**。  
（**思维点睛**：一个数的绝对值最小为0）  
(4) **分析：** |x - 2| + |x + 3| 的几何意义是：数轴上点 x 到点 2 的距离与到点 -3 的距离之和。  
* 当点 x 在 -3 和 2 之间（即 -3 ≤ x ≤ 2）时，这个距离和最小。  
* 最小值 = |2 - (-3)| = **5**。  
*  **答：** |x - 2| + |x + 3| 的最小值是 **5**，此时 x 的取值范围是 **-3 ≤ x ≤ 2**。
