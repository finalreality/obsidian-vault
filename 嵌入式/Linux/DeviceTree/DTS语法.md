## 
```
格式： [标签]:<名称>[@<设备地址>]
```
其中[标签]和[@<设备地址>]是可选项，<名称>是必选项。这里的<设备地址>没有实际意义，只是让节点更方便阅读和理解。如：
```
uart: serial@02288000
```

reg属性
用来描述地址信息，如寄存器地址等
```
格式： reg = <address1 length1 address2 length2 address3 length3 ... ...>
```

如：
```
reg = <0x02200000 0x4000>
或
reg = <0x02200000 0x4000
		0x02205000 0x4000
		>;
```
